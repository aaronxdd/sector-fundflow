# 资金罗盘

移动端优先的 A 股市场与板块看板，Vite + TypeScript，无 UI 框架。

## 运行

```bash
npm install
npm run dev
npm run build
npm run smoke
```

默认地址 http://localhost:5173 。

## 新交互

- 顶部显示沪深两市成交额和上证、深证、创业板指数。两市成交额只相加上证与深证，避免重复计算创业板。
- 默认按板块成交量（手）降序排名，可切换主力净流入排名及升降序。
- 行业 / 概念切换、名称和代码搜索、分批显示，刷新间隔可设置（沿用旧设置，默认 300 秒）。后台页面暂停定时取数。
- 网络异常给出重试提示，刷新失败时保留当前分类上次成功的数据。
- 手机布局使用紧凑榜单与三列指数卡片，桌面显示宽屏布局。

## 数据

东方财富公开行情：f5 为成交量，f6 为成交额，f62 为主力净流入。缺失字段显示「—」，不作为零处理。概念板块可能重叠，不能加总作为市场总量。

默认使用 JSONP；板块主域网络失败时尝试东方财富 push2 备用域。可在 `.env` 设置 `VITE_EM_PROXY=1` 使用 Vite 开发代理。行情可能延迟，页面标注获取时间，不将获取时间当作交易时间。

## 当前入口

- `index.html`：页面结构。
- `src/main.ts`：排名、搜索、刷新及异步切换。
- `src/services/rankings.ts`：板块分页与指数行情。
- `src/services/eastmoney.ts`：请求传输层。
- `src/styles/dashboard.css`：桌面和手机样式。
- `scripts/smoke.mjs`：使用模拟接口验证排序、分页、搜索、缺失值、错误恢复及切换竞态。

## 恢复的旧版查询能力

四个入口：板块排行、资金动向、自选追踪、筛选设置。行业 / 概念为共用数据范围。

- 最强流入、最强流出、净流入 / 净流出板块数和持平数量。
- 正向流入与负向流出双榜，各 Top N 可配置。
- 当日累计主力资金分时，多板块对比；点击板块查看单板块曲线，桌面悬停或手机时间滑块查看各时刻数值。
- 近 N 分钟异动：基于打开页面后积累的快照，支持窗口、阈值、每侧排名数量配置。仅在北京时间交易时段计算，不跨日期、午休或分类拼接。
- 自选名单与独立资金对比，复用旧版 `sf_whitelist`；屏蔽、恢复使用旧版 `sf_blocked`。
- 可选择旧版概念篮子过滤、行业近似名单；自选绕过自动筛选，但仍受手动屏蔽影响。
- 刷新间隔、Top N 和异动参数本地保存。分时最多 4 个并发请求；分类切换时忽略过期结果。

`src/ui/insights.ts` 负责这些交互；分时复用 `src/charts/svgLineChart.ts`。交易日历沿用项目内的 2026 年表，跨年需要更新。接口不可用时显示真实错误或空态，不生成模拟行情用于产品展示。

## 板块内股票排行

点击榜单、自选或资金榜中的板块名称，打开该板块的成分股成交量排行，并保留下方板块资金分时。支持完整分页读取、成交量升降序、名称/代码搜索、分批展示和手动刷新；显示成交量（手）、现价、涨跌幅。切换分类或功能页会关闭详情并忽略迟到响应。

成分股使用东方财富 `clist/get` 的板块过滤 `fs=b:板块代码` 与 `fid=f5`。当前环境该接口返回空响应，真实数据尚待在线验证；模拟接口已覆盖分页、排序、搜索和刷新失败保留数据。

## 最近 30 个交易日回看

顶部交易日选择器提供「最新行情」与从上证日K线提取的最近30个历史交易日（不含今日）。历史模式将大盘、板块成交量、板块日主力净流入及成分股成交量统一到所选日期；现价改为收盘价。个股依据当前板块成分名单回看历史，不宣称还原当时名单。板块集合亦为当前可查询板块。

开发环境优先使用 `/api/history` 同源代理，失败时回退 JSONP；静态构建使用 JSONP，数据源可访问性仍取决于网络。

历史日K线使用 `push2his /api/qt/stock/kline/get`，日资金流使用 `/api/qt/stock/fflow/daykline/get`。每批最多4个标的并发，日数据内存缓存10分钟，当前名单缓存5分钟；切换日期忽略过期响应并停止安排后续请求。主页面刷新可清除历史缓存重试。覆盖数量明确显示，缺失值不会使用当天值或零替代。日期接口失败时可重试，不以固定节假日表推算。

历史模式暂停自动刷新和分钟异动，曲线改为截至所选日的最近30条**每日**主力净流入（非累计），不足30条按实际数据展示。

在线验证：指数历史日行情、半导体历史日资金流已实际返回；板块列表与板块日K线在当前网络仍有空响应，完整真实历史排名待连接恢复后验证。
