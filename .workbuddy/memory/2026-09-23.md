## 把 sector-fundflow 从 JS 重构为 TypeScript

**背景**：项目是 Vite + 原生 ESM 的 A 股板块资金流看板，原来 11 个 `.js` 模块（约 1000 行），无框架无图表库，SVG 手绘。

**做法**：
- 装 `typescript@^5.9.3`；`tsconfig.json` 用 `strict` + `noUnusedLocals/Parameters` + `verbatimModuleSyntax`，`noEmit: true`（转译继续交给 Vite/esbuild），`types: ["vite/client"]`，include `src` + `vite.config.ts`。
- 新增 `src/types.ts`（纯类型：`Settings` / `SectorRow` / `SectorRef` / `IntradayPoint` / `SeriesItem` / `Snapshot` / `AnomalyRow` / `AnomalyResult` / `ChartMeta` / `LineChartResult`），命名元组标注语义。
- 新增 `src/global.d.ts`：`ImportMetaEnv`（VITE_EM_HOST / VITE_EM_PROXY）+ `window.__fundflow` 调试对象声明。
- 11 个 `.js` 全部改 `.ts`，import 改为无扩展名路径；`vite.config.js` → `vite.config.ts`；`index.html` 入口改 `/src/main.ts`。
- 事件总线做成带类型载荷：`EVENTS` 用 `as const`，`EventPayloads` 映射事件名→载荷类型，`on<K extends EventName>` 泛型约束。
- 顺手消了两处重复：`esc()` 统一到 `ui/dom.ts`（原 `svgLineChart.js` 里有一份副本）；主图/白名单图取数逻辑抽成 `fetchSeries(refs)`。
- `package.json` 新增 `typecheck: tsc --noEmit`，`build` 变为 `tsc --noEmit && vite build`。

**校验**：`tsc --noEmit` 零错误；`npm run smoke` 15/15 断言全绿；产物体积 19.34 kB → 19.37 kB（基本持平，确认无行为回归）。

**服务**：`npm run dev` 常驻 http://localhost:5173（`/src/main.ts` 返回 200，类型已被剥离）。

**待办/注意**：`scripts/smoke.mjs` 仍是 JS（Node 侧脚本，故意没转 TS，转的话需要 tsx）。

## 页面风格重构（欧洲财经纸媒编辑排版）

**依据**：项目 `.workbuddy/skills/frontend-design`（来自 anthropics/skills）的两遍法——先规划再自查，规避 AI 默认审美（奶油底+赤陶色、近黑底+荧光强调、均匀圆角卡片、报纸三栏）。

**改动**：
- `tokens.css`：暖纸 `#f2efe9` + 墨色 `#15181d` + 发丝线 `#d6d0c3`；图表区是页面唯一深色墨板 `#12151a`；数据色只留红涨 `#b0322a` / 绿跌 `#1b6b4a`（A 股约定）。圆角收到 2–3px。
- `base/layout/components.css` + `index.html`：去掉全部渐变/网格底纹/软阴影/卡片堆叠，改为 masthead 粗分隔线、4 栏发丝线 lead 统计、下划线式 tab、细线表格。标题用宋体衬线（Songti SC / 思源宋体），正文 Avenir Next。
- `svgLineChart.ts`：配色改为方向感知——流入红系、流出绿系，同方向内按亮度渐变区分序列；墨板内文字 `#e6e2d9`。`crosshair.ts` 提示框用 `<i>` 色条替代圆点。文案去 emoji。

**校验**：`tsc --noEmit` 0 错误；`vite build` 通过（CSS 7.16→8.80 kB，JS 19.56 kB）；无头 Chrome 截图自查，编辑排版观感成立。

**发现的环境问题**：东方财富 `push2.eastmoney.com`（含所有编号镜像/push2delay）当前从本机无法访问——TLS 握手成功但服务端"Empty reply"，带 UA/Referer/ut 令牌、WebFetch 通道均一样；`www.eastmoney.com` 和 `push2his` 根路径可达。故页面数据区显示"—/暂无"，是数据源连通性问题，不是本次改动引入的回归。等接口恢复或换网络即可恢复出数。截图存于 `.workbuddy/preview-restyle.png`。
